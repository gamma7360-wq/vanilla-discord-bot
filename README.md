# 🍦 VANILLA Discord Bot 2.0

Inclui:
- /setup-vanilla — cria cargos, categorias, canais e permissões.
- /ticket — publica painel de tickets.
- Botão Abrir Ticket.
- Ticket privado automático.
- Botões Assumir Ticket e Fechar Ticket.
- Logs de abertura/fechamento.
- Mensagem de boas-vindas.

## Instalação
1. Instale Node.js 18+.
2. Extraia o ZIP.
3. Abra o terminal na pasta.
4. Execute: npm install
5. Renomeie .env.example para .env.
6. Preencha DISCORD_TOKEN, CLIENT_ID e GUILD_ID.
7. Execute: npm run deploy
8. Execute: npm start
9. No Discord: /setup-vanilla
10. Em um canal de suporte: /ticket

O bot não apaga canais existentes.
O comando /setup-vanilla exige Administrador ou Gerenciar Servidor.
